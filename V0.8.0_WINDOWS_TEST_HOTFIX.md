# v0.8.0 Windows Worker Test Hotfix

This hotfix corrects the Windows-only path conversion failure in `multiplayer-server/tests/worker.test.js`.

The test previously passed `new URL(...).pathname` to esbuild. On Windows, that produces a URL pathname such as `/C:/Users/.../v0.8.0%20SERVER%20COPY/...`, rather than a native Windows file path. The test now converts the file URL with Node.js `fileURLToPath()`.

`esbuild` is also declared directly as a development dependency because the Worker test imports it directly.

## Apply manually

Replace `multiplayer-server/tests/worker.test.js` with the corrected copy, then run:

```powershell
npm install
npm test
```
