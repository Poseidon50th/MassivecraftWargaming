# v0.8.0 Army Builder UI Hotfix

This package includes the existing Windows Worker test correction and the following setup-screen changes:

- Widens the singleplayer setup sidebar by approximately 96 CSS pixels on desktop displays.
- Reflows every army-builder unit card so its image and name remain visible above the minus, count, and plus controls.
- Uses three compact columns on wide displays, two columns on narrower desktop displays, and a single responsive row layout on small screens.
- Clarifies that the welcome-screen army builder applies only to player-versus-computer games.
- Clarifies that multiplayer army selection occurs after both opponents are present and the battlefield is approved.
- Adds interface regression assertions for all six unit images, all six unit names, and the multiplayer clarification.
